Security and data handling

How this site and its interactive demos handle data, and how to report a security concern.

Last updated October 29, 2026.

How this site is built

This is a static site. It is made of HTML, CSS and JavaScript files served over HTTPS from GitHub Pages. It has no user accounts, no forms, no database and no server-side code.

What stays in your browser

The site sets no cookies of its own. The portfolio catalog remembers, for the current tab only, which card you opened last, so that it can reopen on that card when you come back. It does this by keeping that page address in your browser's session storage. The value never leaves your browser and disappears when you close the tab.

What is measured

Aggregate traffic is measured with Cloudflare Web Analytics: page views, visits, browser, operating system, country and page load performance. According to Cloudflare, this service does not use cookies or local storage to track individual visitors. The site does not ask visitors for personal data.

The interactive demos

The demos run entirely in your browser and use fictional data only. They do not send data to any server, and they use no forms and no browser storage.

Client and employer information

No client or employer data appears on this site. Case studies are composite and generalized, and demos use invented records.

Reporting a security concern

If you find a problem with this site, write to info@andres-videla.com.
